# 🚆 Train Ticket Price Prediction using Machine Learning

## 📖 Overview
Train ticket prices vary depending on several travel factors such as train type, route, class, and journey details. This project uses a **Linear Regression** model to predict ticket prices based on a real-world dataset.

---

## 🎯 Aim
To build a machine learning model that predicts train ticket prices accurately using historical train travel data.

---

## ❓ Problem Statement
Estimating train ticket prices manually is difficult because prices depend on multiple factors. This project applies Linear Regression to learn patterns from historical data and generate price predictions.

---

## 📂 Dataset
- **Dataset Name:** `data1.csv`
- **Type:** Train Ticket Price Dataset
- **Purpose:** Used to train and test the machine learning model.

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## ⚙️ Methodology
1. Imported required libraries.
2. Loaded the dataset.
3. Cleaned and preprocessed the data.
4. Converted categorical values into numerical values.
5. Split the dataset into training and testing data.
6. Trained a Linear Regression model.
7. Predicted ticket prices.
8. Evaluated the model using RMSE and R² Score.
9. Generated a scatter plot for visualization.

---

## 🤖 Machine Learning Model
**Linear Regression**

Linear Regression is a supervised machine learning algorithm used to predict continuous values by learning the relationship between input features and the target variable.

---

## 📊 Model Evaluation
The model was evaluated using:
- ✅ R² Score
- ✅ Root Mean Square Error (RMSE)

These metrics measure the prediction accuracy of the model.
